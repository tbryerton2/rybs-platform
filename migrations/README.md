# Legacy Migration Archive

The authoritative Supabase migration history for this application lives in
`supabase/migrations`.

This top-level `migrations` directory is a legacy archive from earlier project
organization. It is intentionally left in place for historical reference, but it
is incomplete and is not used by the Supabase CLI, local resets, tests, or
deployment workflow.

Do not add new migrations here. Create new database migrations under
`supabase/migrations`.
